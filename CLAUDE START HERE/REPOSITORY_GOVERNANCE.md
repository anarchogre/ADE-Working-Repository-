# Repository Governance

Status: Canonical

## Purpose
Defines the canonical organization of the ADE repository.

## Principles
- One canonical home for every artifact.
- Preserve provenance.
- Avoid duplication.
- Prefer stable naming.
- Record architectural changes through ADRs.
- Review repository health at checkpoints.
