# ACP-0001 Foundation Gamma Constitutional Amendments
Status: Proposed

## Purpose
Capture governance refinements adopted during Foundation Gamma.

## Proposed Articles
1. Repository Archaeology Principle
   - Discover and classify repository knowledge before authoring new specifications.

2. Markdown Canonical Standard
   - Markdown (.md) is the canonical authoring format. Other formats are derived artifacts.

3. Execution Before Refinement
   - Produce working artifacts before scheduled refinement passes.

4. Artifact Completion Definition
   - Repository work is complete only after:
     - Canonical Markdown updated
     - Downloadable artifact generated
     - CHANGELOG updated
     - Preservation Point created when appropriate

5. Repository Engineering
   - Repository engineering is a standing discipline responsible for provenance,
     consolidation, and duplicate reduction.
